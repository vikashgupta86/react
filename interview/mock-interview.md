# Mock Interview Protocol (Senior React Interviewer)

**Rule:** Claude ek question puchega, tum answer doge. Answer dekhne se pehle attempt karo.

## Har round
1. Tumhara answer
2. Evaluation: kya sahi tha
3. Kya missing tha
4. Correction
5. Interview-ready answer
6. Follow-up question

1. `let/const/var` aur closure
2. State vs props
3. useEffect deps aur cleanup
4. Stale closure scenario
5. Component 20 baar render
6. Context vs Redux
7. Server state vs client state
8. Laravel + React auth design
9. Unnecessary API calls
10. Large app architecture

## Scoring (self)
- Concept clarity /5
- Why/trade-off reasoning /5
- Example /5
- English clarity /5
