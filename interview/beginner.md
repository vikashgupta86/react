# Beginner Interview Questions

| # | Question | 🔵 Short Interview Answer |
|---|---|---|
| 1 | What is React? | A declarative JavaScript library for building UIs from components. |
| 2 | Why React? | Reusable components, efficient updates, large ecosystem. |
| 3 | What is JSX? | Syntax extension compiled to function calls that create React elements. |
| 4 | Component? | Reusable function that takes props and returns UI. |
| 5 | Props vs State? | Props are read-only inputs from parent; state is data owned by the component that triggers re-render. |
| 6 | What are keys? | Stable identity for list items so React can match them between renders. |
| 7 | Controlled component? | Input whose value is controlled by React state. |
| 8 | SPA vs MPA? | SPA loads one page and updates via JS; MPA gets a new page per navigation. |
| 9 | Synthetic events? | React's cross-browser wrapper around native events. |
| 10 | Why can't we mutate state? | React relies on new references to detect changes. |

## Hinglish tip
