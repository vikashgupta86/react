# Final Revision Sheet

## JavaScript
const default, closures, spread immutability, map/filter/reduce, promises/async-await, event loop order.

## React Core
UI = f(state), props read-only, state triggers render, keys = identity, no mutation.

## Hooks
useState (snapshot, functional update), useEffect (sync + cleanup + deps), useRef (no re-render), useMemo/useCallback (measure first), useContext (consumers re-render), useReducer (pure reducer).

## Architecture & API
Service layer, axios instance, 422 mapping, server pagination, CORS backend config.

## Auth
Refresh par `/user`, UI guard != security, cookie vs token.

## Performance & Internals
Profile first, re-render != DOM update, render pure / commit effects.

## Laravel -> React Mental Model
Route->Router, Blade component->Component, Controller->Service layer, Validation->both sides, Middleware->guards (UX) + API auth, Session->auth state, DB->server state.
